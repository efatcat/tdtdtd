# NEON BASTION

Готовая браузерная tower-defense игра без зависимостей и сборки.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages для репозитория.

## Возможности

- 12 волн с постепенно растущей сложностью;
- три класса башен: импульсная, крио и взрывная;
- улучшение и продажа башен;
- элитные враги, здоровье, замедление и урон по площади;
- адаптивная вёрстка для компьютеров и мобильных экранов;
- пауза, ускорение времени, финальные состояния победы и поражения;
- визуальные эффекты, неоновая сетка, трассеры и частицы;
- полностью автономный `index.html`, без внешних библиотек.

## Управление

Выберите башню в арсенале и кликните по свободной платформе вдали от маршрута. Клик по установленной башне открывает её улучшение.
